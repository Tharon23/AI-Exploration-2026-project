# Zasady kursu AI Exploration 2026 — Quick Reference

> Źródło: wiki strona główna GitLab, scraped 2026-10-07

## Ocenianie
- Sprint: 0 (nic), 1 (tak sobie), 2 (zrobione), 3 (pod wrażeniem)
- Lab: 70% sprinty + 30% działający deploy (kontener/binarka/ansible)
- Projekt: średnia z prezentacji

## Workflow
1. Issue w `Open` → assign do siebie
2. Praca → `Doing`
3. Gotowy sprint (dzień wcześniej) → `Review`
4. Po zakończeniu → wiki + zamknij → `Closed`

## Format Issue
```
Opis (edit issue):
  - Aktualny opis zadania
  - Linia: grupa:group_nazwa_grupy

Activity:
  - Raport ze sprintu
  - Etykieta: ~sprint_XX
  - Może być wiele Activity per sprint
```

## Prezentacje
- Min. 3x w semestrze, on-site
- Pokazy IoT: 11.12.2026, 12:00-15:00, B9, 2. piętro

## Wymagania do wyników
- Model: nazwa, wersja, data testu
- Plan: free/paid
- Ustawienia (kwantyzacja dla lokalnych)
- Prompt w tekście (NIE screenshot)
- Powtarzać ten sam prompt wielokrotnie
- Testować darmowe + komercyjne

## Grupy
- 2-4 osoby
- Format: `group_nazwa_grupy: Imię Nazwisko, Imię2 Nazwisko2`
- Prefix `group_` obowiązkowy

## Po zakończeniu projektu
- Wiki z pełnym raportem
- Wszystkie materiały w repo (tekst, obrazki, audio, filmy)
- Nie przesadzać z wielkością plików
